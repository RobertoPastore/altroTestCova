Infrastructure

Section 1: Infrastructure

Evaluate the foundational security measures protecting your core network and server infrastructure. Provide accurate responses based on current configurations.

1.1 Are user passwords encrypted in transit and at rest?

Verify that TLS/SSL is enforced for transit and a strong hashing algorithm (e.g., Argon2, bcrypt) is used for storage.

1.2 Is Multi-Factor Authentication (MFA) mandated for all administrative access?

Includes SSH, VPNs, cloud control panels, and critical internal dashboards.

1.3 Are default vendor credentials changed before systems are deployed?

Applies to routers, switches, IoT devices, and pre-packaged software appliances.

1.4 Is an Intrusion Detection/Prevention System (IDS/IPS) actively monitoring ingress/egress traffic?

Ensure rulesets are updated automatically at least weekly.
